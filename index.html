NULL FILE · package repository

Latest: 1.2.0. Installing a Null File .deb or .rpm from the releases adds this repository for you, so updates come with your other system updates. To add it by hand:

Debian, Ubuntu, Mint, Null OS

sudo curl -fsSLo /usr/share/keyrings/null-grid-archive-keyring.gpg https://null0grid.github.io/null-file/null-grid-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/null-file.sources https://null0grid.github.io/null-file/null-file.sources
sudo apt update && sudo apt install null-file

Fedora, RHEL-family with WebKitGTK 4.1, openSUSE

sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-null-grid https://null0grid.github.io/null-file/null-grid.asc
sudo rpm --import /etc/pki/rpm-gpg/RPM-GPG-KEY-null-grid
sudo curl -fsSLo /etc/yum.repos.d/null-file.repo https://null0grid.github.io/null-file/null-file.repo     # openSUSE: /etc/zypp/repos.d/
sudo dnf install null-file
